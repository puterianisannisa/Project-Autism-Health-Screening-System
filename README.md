## 🧩 Autism Health Screening System

### Overview
A comprehensive web-based application designed to support early autism screening, daily tracking, and analytics. This repository serves as the central codebase for our group project across three core subjects: Software Engineering, Database, and System Development Technology.

### Key Focus Areas
* Software Engineering: Requirement analysis, system architecture, and modular software design.
* Database: Schema design, data integrity, and efficient health/screening query management.
* System Development Technology: Web system integration, UI/UX implementation, and full-stack execution.

### Team
Developed collaboratively by a team of 5 students.
